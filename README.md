# Tabletop Utilities — descarga Android

Utilidades para juegos de mesa: dados, contadores de vida, moneda y grupos aleatorios.
Desarrollada por Guillermo Biemmi con Unity y C#.

Este repositorio contiene únicamente la distribución compilada y su documentación.
El código fuente y el proyecto Unity permanecen en un repositorio privado.
Los archivos automáticos “Source code” de GitHub contienen esta documentación,
no el código de la aplicación. Para instalar, descargar el archivo `.apk` de Releases.

## Versión 1.0.1

- Ícono propio de dado.
- Reset respeta la vida inicial elegida.
- Resultados de grupos con desplazamiento para ver todos los participantes.
- Créditos de recursos incluidos junto a la descarga y dentro del APK.

Android 8 o posterior, procesador ARM64. Versión de demostración con firma de
desarrollo, conservando el firmante del APK original. El APK original fue probado
por su autor en Android; esta revisión se compiló y verificó también en escritorio.
